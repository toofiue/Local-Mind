# Lantern glossary

Every word on screen comes from this list. One name per idea.

## Voice
Calm, direct, brief. Say "click", talk to the person as "you", and don't use "we".

## Things

| Term | Means | Not |
| --- | --- | --- |
| Conversation | One back-and-forth with a model, kept in the sidebar | chat, thread, session |
| Message | What you write and send | prompt, input, query |
| Reply | What a model writes back | answer, response, output, completion |
| Thinking | The reasoning a model writes before its reply | reasoning, thoughts, chain of thought |
| Model | A local AI model installed through Ollama, shown by its Ollama name | LLM, engine, brain |
| Ollama | The app that runs the models on this Mac | server, backend, daemon |
| Code block | A formatted block of code inside a reply | snippet, fence |
| Attachment | An image, PDF, or text file added to a message | upload, file chip |
| Quick Ask | The floating panel opened by the global shortcut | popup, mini chat, spotlight |
| Default Model | The model new conversations and Quick Ask start with | main model, favorite |
| Title | A conversation's name in the sidebar | name, subject |
| Snippet | The bit of text shown under a search result | preview, excerpt |
| Pinned / Recent | The sidebar's two sections once something is pinned | Favorites, Other |

## Actions

| Term | Means | Not |
| --- | --- | --- |
| New Conversation | Start an empty conversation | New Chat, Compose |
| Send | Give your message to the model | Submit, Ask, Go |
| Stop | End a reply that is still being written and keep its text | Cancel, Abort |
| Retry | Replace the latest reply with a new one | Regenerate, Redo |
| Try Again | Reconnect to Ollama after a failure | Reconnect, Refresh |
| Copy / Copied | Put text on the clipboard / the confirmation that it worked | Duplicate |
| Load / Loading | Bring a model into memory / while that happens | Start, Warm up |
| Loaded | A model is in memory now | Running, Active |
| Unload | Take a model out of memory | Eject, Stop, Kill |
| Pin / Unpin | Keep a conversation at the top of the sidebar / undo that | Favorite, Star |
| Delete | Remove a conversation; it can't come back | Remove, Trash |
| Rename | Give a conversation a different title | Edit Title, Retitle |
| Search | Narrow the sidebar to conversations that contain your text | Find, Filter |

## States

| Term | Means | Not |
| --- | --- | --- |
| Stopped | Shown under a reply you ended early | Cancelled, Partial |
| Interrupted | Shown under a reply cut off by a lost connection | Failed, Error |
